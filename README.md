# 四维来客

[English](README.en.md) · 中文

一只四维生物（Clawd）掉进了一个无限展开的二维世界，从一片空白开始行动。像素挂机游戏，不需要操作。

- **网页版**：https://claude.70015.net —— 联网打开过一次以后断网也能玩。Kindle 这类墨水屏浏览器上会自动切成墨水屏模式（每 3 秒画一次、只画白天、窗口精简），也可以用 `?eink=1` / `?eink=0` 手动开关。
- **桌面版（桌宠）**：到 [Releases](https://github.com/fivood/claudewant/releases/latest) 下载 `SiweiLaike_*_x64-setup.exe`。Clawd 会住在任务栏上面来回走、说话；点它展开完整游戏，关掉窗口又缩回去。之后自动更新。
- **会话查看器**：https://claude.70015.net/viewer —— 把 AI 编程助手的会话记录变成能读的对话。

## 玩法

- Clawd 走到哪，纸面就展开到哪；展开的格子换成「感知」，它自己决定先长哪一块。
- **会话当种子**：开始时可以导入一段会话记录（Claude Code、Codex、Kimi Code、Antigravity 的记录，claude.ai / ChatGPT 的数据导出，或 OpenAI 格式的 messages）。对话会变成这张纸：读文件多的积成水，跑命令多的推成山，改文件多的长成森林，出过的错留成裂缝，你说过的话由居民念出来。文件只在本地读，不上传。导入框里的 tips 写了各家记录放在哪。
- **对话之路和会话奇观**：对话被画成一条四维曲线，它在纸上的影子是一条路；路边立着从对话里长出来的像素立体物（开篇碑、改得最多的文件、出过的错、部署和构建……），影子跟着你那边的太阳走。Clawd 会想起自己在那段对话里说过、想过的话。
- **地貌**由种子决定：地球、二向箔、沙丘、索拉里斯、晶化、电路板、水墨、蓝图、切片。有的会动：地球的山按左上来光打了晕渲，云影飘过、水面有波光；沙丘上风卷细沙，沙虫在沙底下游过去，大的会浮出半截；电路板照真板子画（芯片、电阻电容、晶振、接插件、铺铜过孔、丝印标号），数据包顺着铜线跑到焊盘上闪一下，Clawd 走过偶尔短路打出火花、元件冒烟留下焦痕；二向箔画成梵高那样一笔笔打旋的油画笔触，被压平的行星是一圈圈摊开的地层，房子是立方体的展开图，一圈圈压平的余波扫过去；索拉里斯的海在呼吸，偶尔盯着 Clawd 漾开涟漪；地面由各种晶形的晶体无缝拼成，沿轮廓按矿物的脾气发光，一块光斑在晶体间挪；水墨是一整幅画：奇峰、瀑布崖、江岸柳村、松下、山寺……一处处小景拼起来，瀑布一直往下流、江面水纹在漂，全图的时候裱成一幅立轴；蓝图画的是一座有入口和出口的地下迷宫，形状各异的房间由走廊连着，一支看不见的笔在图上画线、偶尔一个红笔圈；切片照 HE 染色的组织切片画（上皮、腺体、纤维、淋巴组织、软骨、脂肪、血管），血管里红细胞在流，细胞分裂时染色体排成一排再拉开，白细胞围到 Clawd 刚站过的地方，偶尔一个白细胞追着细菌把它吞掉。
- **深空**：不导入会话直接开始的纸是透明的，展开的地方能看见背后的真实天空。视角和比例尺都随机：有时是一大片星图（银河按真实银道坐标画），有时像望远镜对准某个天体放大到几百格。六十多个有名的星系、星云、星团和亮星放在真实的位置上，颜色照哈勃和韦布的照片调，亮星带韦布的六条星芒；走到跟前 Clawd 会说说它的来历，名字标在图上。深空不分昼夜。住在这里的是几种糅了科幻小说和电影的外星生物（七肢体、毛团、触角人），它们的城是带环、带条纹的行星，庙是方碑，历史从漂流、落地一直走到心理史和星孩。天上的东西是在第四个方向上穿过这张纸：亮星的截面忽大忽小，流星凭空冒出来、滑一小段又消失，垂直穿过的流星会在白纸上烧出一个洞，卫星沿一条线段来回摆。
- **二维居民的历史**在载入时就由种子推演完了：人口、纪元（游荡 → 村落 → 城邦 → 几何 → 觉醒）、城镇、战争、神殿，直到它们离开纸面。同一段会话永远是同一部历史。四维生物能看见整条时间线，纪年里淡色的是还没发生的事。
- **昼夜**跟着你那边的真实时间，也可以在感知窗口的时间条上手动拨。
- **全图**可以把整张纸铺开下载成 PNG，还能看这段对话的四维投影；深空的纸在这里是星表，看过的天体一张卡片。
- 升级到「补白」以后多一个按钮，一键补上走过的地方围起来、却没踩到的空格。「清除记录」会删掉这台机器上所有纸的进度和读过的会话，要确认两次。「地貌」下拉框能把同一张纸（同一个种子、同一段会话）换成别的地貌，这张纸的探索进度会清空。
- **桌宠 = 线国**：纸面上的 Clawd 是立体的，走路时侧身、迈腿、摆手、前倾，停下来转回来看着你；缩成桌宠时它也成了平面生物，世界塌成一条线；遇到奇观要爬、被发射、穿过锻炉，或者往第四个方向绕过去。线国的人只看得见这条线，Clawd 看得见线后面的纸：有山有林的地方，背后是一层层越远越淡的山影和树梢，脚下飘着雾。
- 右下角的电台是 WebAudio 现场合成的十个台，每种地貌一首（深空那首是管风琴、滴答声和慢慢堆起来的琶音），风格各不相同，都能一直循环挂着听。默认放这张纸的那首，» 换台，「随」每隔几分钟随机换。
- 中英文随时切换（感知窗口时间条旁边的按钮）。

## 目录

```
web/          网页本体（纯静态，无构建）：index 开始页、game 游戏、viewer 会话查看器、parse.js 各家记录解析、i18n.js 中英切换
  js/         游戏脚本，按顺序加载的普通脚本（共享全局作用域）：
              world 存档/地形/分块画布 · ink 水墨的画（小景拼接、装裱） · fx 地貌动画 · sky 深空 · life 升级与行走 · talk 台词 · ui 界面 · render 画面与主循环
              civ 每种地貌的居民 · history 二维历史 · wonders 对话之路/会话奇观/全图 · radio 电台 · pet 桌宠 · start 开始
src-tauri/    桌面版外壳（Tauri 2），前端直接用 web/
test.mjs      解析器测试
build.mjs     部署前把 web/ 降成 Kindle 浏览器（约 Chromium 74）也能跑的版本，输出 dist/
```

## 开发

```bash
node test.mjs                     # 测试
npx serve web                     # 本地看网页（任何静态服务器都行）
npm install && npx tauri dev      # 本地跑桌面版
```

文字都写成 `tr('中文', 'English')`，页面上的静态文字用 `data-en`，见 `web/i18n.js`。

发布网页：`npm run deploy`（先 `build.mjs` 转出 dist/，再部署 dist/）。源码照常写新语法，esbuild 会降；但 `.at()`、`replaceAll` 这类 Chrome 74 没有的函数别用，构建会拦下来。

发布桌面版：把 `src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml`、`package.json` 里的版本号改成同一个新版本，提交后推一个 `v<版本号>` 标签，GitHub Actions 会打包并发布，已安装的客户端会自己更新。
